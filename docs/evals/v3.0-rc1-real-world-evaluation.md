## Retry Evaluation

Retry behavior was actually exercised on E03. The first complete composition selected sparse-object because the layout selector evaluated generous negative space before the landscape scene trigger. Visual QA identified the result as a layout mismatch for a long-horizon marsh scene. One targeted source-traceable correction moved the landscape trigger ahead of the generic sparse-object/negative-space branch. The focused regression test failed before the fix and passed after it. E03 was recomposed once, then revalidated and visually reviewed as wide-horizon.

This was two total composition attempts, with one targeted correction and no unbounded regeneration loop. The retained first attempt is result-attempt-1.png in the E03 directory.

## Bugs Found / Fixed

One real product bug was found during RC1 evaluation:

- Symptom: a landscape with generous negative space selected sparse-object instead of wide-horizon.
- Cause: the generic negative-space branch preceded the landscape scene branch in select_layout_profile().
- Reproduction: the new deterministic test case for scene_profile=landscape and negative_space=generous failed with expected wide-horizon and actual sparse-object.
- Fix: prioritize landscape/wide-horizon scene triggers before still-life/minimal-object and generous/large negative-space fallback.
- Regression: focused test passed after the fix; the full suite and E03 validator were rerun after correction.
- Scope: only layout routing and its regression test changed; no unrelated behavior was altered.

## Remaining Limitations

- Other Agent runtimes and native image-generation/edit modes remain untested; this report does not generalize the DeepSeek result to every Agent.
- Image-generation outputs can vary across Agents and runs; this evaluation records the exact local inputs used here, not universal generation determinism.
- Abstraction, Freedom, Identity, and Spatial controls are currently orchestration-level decisions and prompt contracts, not numeric compositor arguments with machine-scored output.
- Native Image Edit and Reference Generation modes were not represented as local runtime executions in this Strict Fidelity evaluation; their documented limitations remain applicable.
- No separate image-generation failure/retry was required; the retry evidence covers a real composition/layout correction.
